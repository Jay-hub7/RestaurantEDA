# Restaurant Branch Performance EDA

This project performs Exploratory Data Analysis (EDA) on a restaurant branch performance dataset to understand patterns in revenue, profit, customers, marketing spend, staff count, delivery time, and customer ratings.

## Analysis Performed

* Dataset inspection and descriptive statistics
* Distribution analysis of key numerical variables
* Branch, region, and store type performance comparison
* Analysis of relationships between important business variables
* Correlation matrix of numerical features
* Key data-driven observations

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Conclusion

The analysis highlights important differences in branch and store performance and identifies relationships between factors such as customers, revenue, staffing, marketing spend, delivery time, and customer ratings.
